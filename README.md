# Data Pipeline – Bronze & Silver (PySpark)

Este proyecto implementa un pipeline de datos simple siguiendo una arquitectura **Bronze / Silver**, usando **PySpark en modo local**.

El objetivo es:
- Ingerir eventos financieros desde CSV (Bronze)
- Aplicar tipado, reglas de calidad y cuarentena (Silver)
- Generar métricas básicas de calidad de datos
